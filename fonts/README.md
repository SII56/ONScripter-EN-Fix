# Bundled fallback font

Noto Sans Mono CJK SC Regular, unmodified, from the official Noto CJK project:
https://github.com/notofonts/noto-cjk/blob/f8d157532fbfaeda587e826d4cd5b21a49186f7c/Sans/Mono/NotoSansMonoCJKsc-Regular.otf

License: SIL Open Font License 1.1; see OFL.txt. Copyright and font metadata
remain embedded in the original font. This font has half-width Latin characters
and full-width CJK characters, suitable for legacy character-cell layouts.
The SC variant uses Simplified Chinese regional glyph forms and also covers
Traditional Chinese and Japanese; a game's own font takes priority.
